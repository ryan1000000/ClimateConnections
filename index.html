GeoMet SWOB Extremes

Top stations within the current map view (bbox), sorted by the metric (not by update time).
Idle
Pan/zoom to change the search area. Each category requests GeoMet SWOB real-time within the current bbox, sorted by the metric, then deduplicates by station ID to build a true “top N stations” list.
Notes: GeoMet item responses are capped per request (commonly 500), so this pages with offset. :contentReference[oaicite:2]{index=2} For public deployment, add a small backend cache.

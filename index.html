GeoMet SWOB Extremes

Ranks stations within the current map view (bbox) using SWOB real-time.
Idle
Pan/zoom to change the search area. Each category shows the top stations within the current map extent. Results are deduplicated by station (most recent observation that has the metric within the lookback window).
Notes: This prototype queries GeoMet directly from your browser (no caching). If you plan to share publicly, a small backend cache is recommended.
